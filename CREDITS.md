# Credits

AnimeLover borrows design ideas (the “Vibrant Dark” palette, anime page layout, double tap ±10 s) from OpenStream: https://github.com/Ivorisnoob/OpenStream

Data: AniList (https://anilist.co) for ratings, years and genres; AniSkip (https://aniskip.com) for openings/endings; TMDB (https://www.themoviedb.org) for episode titles and localized synopses.

This product uses the TMDB API but is not endorsed or certified by TMDB.
